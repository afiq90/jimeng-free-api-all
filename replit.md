# jimeng-free-api

## Overview
A free API server for jimeng (即梦) AI image/video generation service. Provides OpenAI-compatible API endpoints for integration with clients like LobeChat, NextChat, Dify, etc.

## Project Architecture
- **Language**: TypeScript (Node.js)
- **Framework**: Koa.js web server
- **Build Tool**: tsup (bundler)
- **Port**: 5000 (configured in `configs/dev/service.yml`)
- **Host**: 0.0.0.0

### Directory Structure
- `src/` - Source TypeScript code
  - `api/` - API routes and controllers
  - `lib/` - Core libraries (server, config, logger, etc.)
- `configs/dev/` - Development configuration (service.yml, system.yml)
- `public/` - Static files (welcome page)
- `dist/` - Built output (generated by `npm run build`)

### Key Commands
- `npm run build` - Build the TypeScript project
- `npm run start` - Start the production server
- `npm run dev` - Start development server with watch mode

### API Endpoints
- `/v1/chat/completions` - Chat completions (OpenAI-compatible)
- `/v1/images/*` - Image generation
- `/v1/videos/*` - Video generation
- `/ping` - Health check
- `/token/*` - Token management
